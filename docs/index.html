Documentation

Introduction

DB Manager is a powerful, web-based database management tool built with Node.js and Express. It provides a modern alternative to phpMyAdmin with a clean Bootstrap 5 interface, multi-connection support, and advanced features like SQL formatting, EXPLAIN queries, and CSV/SQL import and export.

Prerequisites

  • Node.js v14 or higher
  • MySQL or MariaDB server (local or remote)
  • A Git client to clone the repository

Installation

git clone https://github.com/mohit31kumar/db-manager.git
cd db-manager
npm install

This installs all required dependencies including mysql2, bcrypt, express, and ejs.

First Run

  1. Copy .env.example to .env and configure your settings.
  2. Create the internal MySQL database and run the schema SQL.
  3. Start the server: npm start
  4. Open http://localhost:3000 in your browser.
  5. Register your first admin account.
  6. Add your first database connection and start managing databases.

Configuration

Edit the .env file in the project root. All variables are optional except SESSION_SECRET and the internal MySQL connection settings.

SESSION_SECRET=your-secret-key-here
APP_PORT=3000

# Internal MySQL database for app data
INTERNAL_DB_HOST=localhost
INTERNAL_DB_PORT=3306
INTERNAL_DB_USER=root
INTERNAL_DB_PASSWORD=
INTERNAL_DB_NAME=db_manager
INTERNAL_DB_SSL=false

Variable Reference

VariableDefaultDescription
SESSION_SECRETfallback-secretSecret key for signing session cookies. Use a strong random string in production.
APP_PORT3000Port the Express server listens on.
INTERNAL_DB_HOSTlocalhostMySQL host for internal app data (users, connections, saved queries).
INTERNAL_DB_PORT3306MySQL port for internal app data.
INTERNAL_DB_USERrootMySQL username for internal app data.
INTERNAL_DB_PASSWORDMySQL password for internal app data.
INTERNAL_DB_NAMEdb_managerMySQL database name for internal app data.
INTERNAL_DB_SSLfalseSet to true if your MySQL server requires SSL (e.g., TiDB Cloud, AWS RDS).

SSL Setup

If your MySQL server requires SSL (common with cloud providers like TiDB Cloud, AWS RDS, Google Cloud SQL), set INTERNAL_DB_SSL=true in your .env file. DB Manager will automatically configure rejectUnauthorized: false for the internal connection.

For user-facing connections, SSL is auto-detected based on the server's response. You can also manually enable SSL when adding a connection in the UI.

User Guide

Managing Connections

After logging in, go to Connections to manage your database connections.

  • Add Connection — Click "Add Connection" and enter the host, port, username, password, and database name. Enable SSL if required.
  • Edit Connection — Click the edit icon next to any connection to update its details.
  • Delete Connection — Click the delete icon to remove a connection. This also clears the connection pool.
  • Activate Connection — Click "Activate" to switch the active connection. The dashboard will load databases from the active connection.

Connections are stored securely with bcrypt-hashed passwords in the internal MySQL database.

Browsing Databases and Tables

From the dashboard, you can:

  • View all databases on the active connection
  • Click a database to browse its tables
  • Create new databases with custom collation
  • Drop databases with confirmation
  • View table structure, indexes, and CREATE TABLE SQL

Table Management

Inside a database, you can manage tables:

  • Structure — View columns, types, keys, and indexes
  • Add Column — Add new columns with full type configuration
  • Modify Column — Change column types, nullability, defaults
  • Drop Column — Remove columns with confirmation
  • Change Engine — Switch between InnoDB, MyISAM, MEMORY
  • Change Collation — Update table character set and collation
  • Rename Table — Rename tables with confirmation
  • Truncate — Remove all rows quickly with confirmation

SQL Query Editor

The SQL editor provides a rich editing experience:

  • Syntax-highlighted code editor (CodeMirror)
  • Execute arbitrary SQL queries
  • EXPLAIN support to analyze query performance
  • SQL formatting and prettification
  • Export results as CSV, SQL, or JSON
  • Query history stored in localStorage
  • Ctrl+Enter keyboard shortcut to run queries

Import / Export

Import

  • Import SQL dump files with line-by-line error reporting
  • Import CSV files with column mapping and custom delimiters

Export

  • Export query results as CSV, SQL INSERT statements, or JSON
  • Custom CSV delimiter support

Troubleshooting

Common Errors

Access denied for user

Verify the MySQL username and password in your connection settings. Ensure the user has the necessary privileges on the target database.

Connections using insecure transport are prohibited

Your MySQL server requires SSL. Enable SSL in the connection settings or set INTERNAL_DB_SSL=true for the internal database.

Port 3000 already in use

Change the port in .env: APP_PORT=3001

Pool is closed

The connection pool was refreshed due to a timeout or network issue. Try the action again, or re-add the connection if the problem persists.

ETIMEDOUT / ECONNREFUSED

Check that the MySQL server is running, the host and port are correct, and firewall rules allow the connection.

Security

Session Security

DB Manager uses express-session with httpOnly cookies and sameSite: lax protection. Always use a strong, random SESSION_SECRET in production.

Password Storage

User passwords are hashed with bcrypt (cost factor 10). Connection passwords are stored in the internal MySQL database.

Internal Database Isolation

The internal MySQL database stores users, connections, and saved queries. It is separate from the user-facing database connections and should be configured with restricted access.

Best Practices

  • Never commit .env to version control
  • Use strong MySQL passwords and limit user privileges
  • Enable SSL for remote MySQL connections
  • Regularly backup the internal MySQL database
  • Keep Node.js and dependencies up to date
