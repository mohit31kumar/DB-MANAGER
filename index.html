DB Manager

A powerful, web-based database management tool built with Node.js — a modern alternative to phpMyAdmin.

Get Started View on GitHub
Multi-Connection Support

Connect to multiple MySQL/MariaDB databases simultaneously. Add, edit, delete, and switch between connections with ease.

Secure by Default

Password hashing with bcrypt, session-based auth, SSL/TLS auto-detection for cloud databases, and per-user isolated connections.

SQL Query Editor

Syntax-highlighted editor with EXPLAIN support, SQL formatting, export to CSV/SQL/JSON, and Ctrl+Enter shortcuts.

Table Management

View structure, add/modify/drop columns, change engines and collations, rename tables, and truncate with confirmation.

Import / Export

Import SQL dumps and CSV files with error reporting. Export query results in multiple formats with custom delimiters.

Responsive Design

Clean Bootstrap 5 UI with collapsible sidebar, toast notifications, and a mobile-friendly layout that works everywhere.
